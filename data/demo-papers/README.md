# Real research papers for the demonstration

Download the original papers from their official publishers into this directory:

- `lewis_2020_rag.pdf`: Lewis et al., Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks, NeurIPS 2020. [Official PDF](https://papers.neurips.cc/paper/2020/file/6b493230205f780e1bc26945df7481e5-Paper.pdf).
- `asai_2023_self_rag.pdf`: Asai et al., Self-RAG. [Official PDF](https://arxiv.org/pdf/2310.11511).
- `min_2023_factscore.pdf`: Min et al., FActScore. [Official PDF](https://arxiv.org/pdf/2305.14251).

These are external research papers, separate from the synthetic example in `output/pdf/`. The optional real-paper integration test runs when the RAG PDF is present. See `docs/complete-feature-demo.md` and `docs/researchmind-viva-guide.md` for the walkthrough and preparation guide.
